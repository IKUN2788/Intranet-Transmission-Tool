# 局域网文件传输工具

一个基于Python和tkinter开发的局域网内文件传输GUI工具，支持在同一局域网内的设备间快速传输文件。

## 功能特点

- 🖥️ **图形化界面**: 基于tkinter的现代化GUI界面
- 🌐 **局域网传输**: 支持在同一局域网内的设备间传输文件
- 📁 **多文件传输**: 支持同时选择和传输多个文件
- 🔄 **双向传输**: 既可以作为服务器接收文件，也可以作为客户端发送文件
- 📊 **实时进度**: 显示文件传输进度和状态
- 📝 **传输日志**: 详细的传输日志记录
- ⚙️ **自定义设置**: 可自定义端口和下载路径

## 系统要求

- Python 3.6 或更高版本
- Windows/Linux/macOS 操作系统
- 同一局域网环境

## 安装和运行

1. **克隆或下载项目文件**
   ```bash
   # 确保你有以下文件:
   # - file_transfer_gui.py
   # - requirements.txt
   # - README.md
   ```

2. **运行程序**
   ```bash
   python file_transfer_gui.py
   ```

## 使用方法

### 1. 启动服务器（接收文件）

1. 运行程序后，程序会自动显示本机IP地址
2. 可以修改端口号（默认8888）
3. 点击"启动服务器"按钮
4. 设置文件下载路径（默认为用户下载文件夹）
5. 等待其他设备连接并发送文件

### 2. 发送文件

1. 点击"选择文件"按钮，选择要发送的文件
2. 输入目标设备的IP地址
3. 确保目标设备已启动服务器
4. 点击"发送文件"按钮开始传输

### 3. 查看传输状态

- 传输日志区域会显示详细的传输信息
- 状态栏显示当前操作状态
- 传输过程中会显示实时进度

## 网络配置

### 端口设置
- 默认端口: 8888
- 可在界面中修改端口号
- 确保防火墙允许该端口的通信

### IP地址
- 程序会自动检测并显示本机IP地址
- 发送文件时需要输入目标设备的IP地址
- 确保两台设备在同一局域网内

## 防火墙设置

### Windows
1. 打开Windows防火墙设置
2. 允许Python程序通过防火墙
3. 或者允许指定端口（如8888）的入站连接

### Linux/macOS
```bash
# 使用ufw允许端口（Ubuntu）
sudo ufw allow 8888

# 或者临时关闭防火墙进行测试
sudo ufw disable
```

## 故障排除

### 常见问题

1. **无法连接到目标主机**
   - 检查目标IP地址是否正确
   - 确保目标设备已启动服务器
   - 检查防火墙设置
   - 确保两台设备在同一局域网内

2. **文件传输中断**
   - 检查网络连接是否稳定
   - 确保有足够的磁盘空间
   - 检查文件是否被其他程序占用

3. **程序无法启动**
   - 确保Python版本为3.6或更高
   - 检查是否有其他程序占用端口
   - 尝试以管理员权限运行

### 获取本机IP地址
如果程序显示的IP地址不正确，可以手动查看：

**Windows:**
```cmd
ipconfig
```

**Linux/macOS:**
```bash
ifconfig
# 或者
ip addr show
```

## 技术实现

- **数据序列化**: json

## 安全注意事项

- 本工具仅适用于可信任的局域网环境
- 不建议在公共网络中使用
- 传输的文件未加密，请注意数据安全
- 建议在使用后关闭服务器功能
